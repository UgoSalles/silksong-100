# Silksong 100 %

Route de 100 % de *Hollow Knight: Silksong* en moins de 30 h, à cocher étape par étape, sur téléphone (PWA, fonctionne hors ligne une fois ouverte).

Appli : https://ugosalles.github.io/silksong-100/

## Installer sur iPhone
Ouvrir le lien dans Safari, puis Partager, puis « Sur l'écran d'accueil ». L'appli s'ouvre ensuite en plein écran. La progression est gardée sur l'appareil ; « Infos » permet de la copier et de l'importer.
